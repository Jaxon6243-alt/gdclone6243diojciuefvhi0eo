# Dash Forge

A Geometry Dash-inspired browser game with:
- main menu
- campaign levels
- level editor
- JSON export/import for custom levels
- shareable custom level files

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` – app shell and UI
- `style.css` – neon Geometry Dash-inspired styling
- `script.js` – gameplay, editor, and JSON import/export logic

## Features

- Jump and auto-run platformer gameplay
- Built-in campaign levels
- Simple level editor for placing platforms, spikes, and goals
- Export custom levels as JSON
- Import custom levels back into the game to share or test
